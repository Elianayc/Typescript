23. Sistema Integral de Vigilancia

La empresa tecnológica Kokumo Tech Inc. (KTI) desarrolla un sistema 
integral de vigilancia capaz de monitorear tanto aire como tierra, 
destinado a barrios privados, estancias y grandes extensiones de terreno.

Para ofrecer una solución unificada, KTI necesita integrar la información
proveniente de distintos dispositivos, cuyos formatos de datos son 
diferentes.

a. Gr0N3
Gr0N3 es un dispositivo aéreo (drone) capaz de detectar objetos y 
clasificarlos según su tamaño (grande, mediano o pequeño). 

Además, puede determinar si el objeto detectado corresponde a un humano
o a un animal.

Los datos de un drone se obtienen invocando el método estático 
getData(id) de la clase FlyingGr0n3, donde id representa el identificador
del dispositivo (valores del 1 al 10).

- Si el identificador no existe, el método lanza una excepción.
- Si el identificador es válido, devuelve una lista (que puede estar 
vacía) de objetos de tipo Gr0n3Object.

Cada Gr0n3Object posee los siguientes atributos:
- size (string): valores posibles big, medium, small.
- type (string): valores posibles human, animal.
- kind (string): si type es animal, los valores posibles son dog, 
cat, cow, sheep, horse o undefined.

------------------------------------------------------------

b. FalderPerr177

FalderPerr177 es un dispositivo terrestre que distingue entre humanos 
y no humanos y, además, es capaz de identificar el género biológico de 
las personas.

Los datos se obtienen mediante una instancia de la clase FalderP, 
invocando el método getData().

Este método devuelve una lista que contiene todas las unidades 
terrestres activas, representadas mediante objetos de la clase Perr177.

Cada objeto Perr177 posee:

- id (number): identificador numérico del dispositivo.
- data (List<Perr177Data>): lista de detecciones realizadas por ese 
dispositivo.

Cada objeto Perr177Data posee los siguientes atributos:

- type (string): valores HUMAN o NO_HUMAN, representados mediante 
el enum FPType.
- size (string): valores posibles rande, pichitito, niranipi.
- gender (string): valores MALE o FEMALE, representados mediante el 
enum FPGender.

------------------------------------------------------------

Objetivo

Implementar una clase que contenga la función fetchSurveillanceData().

Esta función deberá:

1. Obtener los datos de ambos sistemas de vigilancia.
2. Transformar la información a un formato homogéneo.
3. Devolver el resultado para que pueda ser procesado por la función 
printInfo().

La salida deberá mostrar, para cada detección, la siguiente información:

Dispositivo: <id del dispositivo>
Tipo: <Humano | No humano>
Tamaño: <Grande | Mediano | Pequeño>
Observaciones: <kind o gender, según corresponda>
